# Security

## Reporting a vulnerability

Found something that could put a Nulvless project or its users at risk? Send it to **security@nulvless.com** instead of opening an issue — issues here are public, and a report deserves a fix before it has an audience.

Include what we need to reproduce it without guessing: the SDK version, the steps or code involved and the impact you observed. We confirm we received it and keep you posted while it is investigated and fixed.

The full disclosure policy is at [nulvless.com/security/disclosure](https://nulvless.com/security/disclosure).

## Supported versions

Security fixes are released for the latest published version.
